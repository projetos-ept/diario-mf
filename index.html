Importar turmas

Cole um JSON estruturado ou escolha um arquivo. A importação mescla alunos e disciplinas pelo identificador.

Exemplo pronto: 9º ano com 5 alunos
{
  "turmas": [
    {
      "id": "9-ano-exemplo",
      "nome": "9º ANO (exemplo)",
      "turno": "MATUTINO",
      "professor": "NOME DO PROFESSOR",
      "disciplinas": [
        { "id": "matematica", "nome": "Matemática" }
      ],
      "alunos": [
        { "id": "01", "nome": "ALUNO EXEMPLO UM" },
        { "id": "02", "nome": "ALUNO EXEMPLO DOIS" },
        { "id": "03", "nome": "ALUNO EXEMPLO TRÊS" },
        { "id": "04", "nome": "ALUNO EXEMPLO QUATRO" },
        { "id": "05", "nome": "ALUNO EXEMPLO CINCO" }
      ]
    }
  ]
}

Troque o id, o nome e os alunos pelos da sua turma real antes de importar — a importação mescla pelo id, então um id igual ao de uma turma existente altera essa turma em vez de criar uma nova.

Modelo A4 paisagem preenchido com todas as unidades do ano e a frequência da turma.

Como funciona: os cabeçalhos, categorias, pontuações, datas, notas e médias podem ser editados. A média de cada unidade pode ser preenchida diretamente, mesmo quando as três notas parciais estiverem vazias. O HTML exportado é uma cópia independente e não altera os dados do sistema.

Configurações

Personalize o sistema para a sua escola: identificação, unidades do ano, padrões de avaliação, textos do diário oficial e cadastro de turmas e alunos.

Escola

Aparece no cabeçalho do aplicativo, nos relatórios e no diário oficial.

Unidades do ano

Bimestres, trimestres ou unidades: escolha quantas divisões o ano letivo tem e como cada uma se chama.

Cada unidade continua valendo 10 pontos.

Padrões de avaliação

Usados quando uma unidade nova é aberta em qualquer turma. Unidades já configuradas em Cadastros não mudam.

Diário oficial — textos

Rótulos impressos no modelo oficial. Deixe em branco para voltar ao padrão.

Turmas e alunos

Cadastre turmas e alunos diretamente aqui ou importe um JSON em Cadastros. Excluir uma turma apaga também as chamadas, atividades e notas dela.

Começar do zero

Remove todas as turmas, alunos, chamadas, atividades e notas deste aparelho (e da nuvem na próxima sincronização). Escola, unidades e padrões são mantidos. Exporte um backup antes.
